Privacy Policy: Misty Lake Cabin Live

Last updated: November 13, 2026

Misty Lake Cabin Live ("the app") is a private tool used only by the owner of the YouTube channel Misty Lake Cabin to manage live streams on that channel. It is not offered to other users.

What the app accesses

With the channel owner's permission (Google OAuth, scope youtube), the app uses the YouTube Data API to create live broadcasts on the owner's channel, connect them to the channel's stream, set their titles, descriptions and thumbnails, and end them.

What the app stores

The app stores only an OAuth refresh token on the owner's own server, so it can keep managing the live streams. It does not collect, store or share personal data of viewers or of anyone else.

Sharing

No data is sold or shared with third parties. Data obtained from Google APIs is used only for the purposes described above, in line with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
